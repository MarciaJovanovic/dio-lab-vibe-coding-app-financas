## 💡 Resumo do App
O **Finanças Vibe** é um aplicativo que:
- Registra gastos via conversa.
- Classifica automaticamente despesas.
- Cria metas financeiras personalizadas.
- Dá dicas de economia com IA.
- Mostra relatórios simples e bonitos.
